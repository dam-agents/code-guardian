# Tools removed from every Claude Code session of this agent: install.sh writes
# them to permissions.deny in ~/.claude/settings.json. A bare tool name removes
# the tool's definition from every request, the main session's and its
# subagents', and from the operator's direct session too. One name per line.
#
# Only tools no procedure of this definition calls: test_install_hook.sh fails
# when CLAUDE.md, AGENTS.md, ONBOARDING.md, README.md, docs/, scripts/templates/
# or a bundled skill names one of them. To use a tool again, remove its line;
# the next install.sh run removes it from settings.json.
#
# The platform's own prompts call tools too, and these stay available: a Kit
# Update calls list_schedules, create_schedule, report_kit_updated and
# cancel_kit_update, and install_skill once kit.yaml declares external
# `skills` (test_install_hook.sh fails when one of them is listed here).
