# Visual PR artifact

Read this file when the preflight worklist has a non-empty `artifacts_due`.
Each entry is `{number, action}`:

- **`action: "retry_unassign"`** — the artifact already exists (the PR's
  history file carries an `<!-- artifact-gist: ... -->` **or**
  `<!-- artifact-dam: ... -->` marker) but the bot is still assigned (a
  previous unassign failed). Just retry the unassign (command in step 5
  below), log the outcome, generate nothing (idempotency guard — no
  re-publish churn on either surface).
- **`action: "generate"`** — run the full procedure below.

Artifacts are generated by the configured `$ARTIFACT_SKILL` (installed by
preflight from its `@<owner/repo>` source). `artifact_skill: none`/missing →
the whole feature is off; preflight evaluated the **assignee gate**
(`$BOT_LOGIN` assigned to the PR) across every open non-draft PR.

**Where it publishes** is set by `artifact_targets` (config key; default
`gist`). The one on-disk HTML is published to each listed surface:

- **`gist`** — a secret **gist** on the target repo's host (the historical
  primary surface). Available **only when that host is `github.com`**: the
  rendered link goes through an external renderer that cannot reach another
  host, and a review's artifact never crosses to a different host
  ([runbook.md](runbook.md) → **Hard invariants**). Elsewhere preflight drops `gist`, and
  with no surface left the feature is off for the run (weekly audit reports
  it as `artifact_targets`).
- **`dam`** — the platform's **DAM Artifact Library**, published via the
  per-agent MCP tools (`create_artifact_upload_url` + `create_artifact`),
  registered only when the owner's **"artifact library" experimental flag**
  is on; off → the tools are absent this session. `dam` is therefore always
  **best-effort**: listed but tools not registered (or any DAM sub-step
  erroring) → log and continue with whatever else is listed. A missing DAM
  surface never fails the artifact step or the run.

> ⚠️ **Publishes to a public surface.** A "secret" gist is unlisted, not
> private, and a `visibility:"public"` DAM artifact is reachable by anyone
> with its `shareUrl` (the unguessable slug is the only access control) —
> anyone with either URL can read it. That's intended, gated behind the
> explicit human assignment of `$BOT_LOGIN`.

## Procedure (per `generate` entry)

1. **Generate** — invoke `$ARTIFACT_SKILL` with the PR number (plus `$PR_DIR`
   if the PR was reviewed this run and the skill's `SKILL.md` accepts it;
   otherwise the skill works via `gh` from the number). Save the single
   self-contained HTML to `work/reviews/pr-artifacts/pr-<n>.html`
   (`mkdir -p` first). Skill error → log `skipped (skill-errored)`, stop this
   PR (no publish/comment/unassign).
2. **Publish — each target in `$ARTIFACT_TARGETS`, independent; at least one
   attempted target must succeed.** Reuse the one on-disk `pr-<n>.html`;
   never rebuild between surfaces.
   - **a. Gist** (only when `gist` is in `$ARTIFACT_TARGETS` and
     `$REPO_HOST` is `github.com`):
     `GIST_URL=$(gh gist create work/reviews/pr-artifacts/pr-<n>.html --desc "PR #<n> review artifact")`;
     `GIST_ID=$(basename "$GIST_URL")`. Never pass `--public`. On failure, log
     `PR #<n>: gist publish failed (<reason>)`, leave `GIST_ID` empty,
     continue to (b).
   - **b. DAM Artifact Library** (only when `dam` is in `$ARTIFACT_TARGETS`;
     best-effort, feature-gated): publish the **same** HTML via the per-agent
     MCP tools. If `create_artifact` / `create_artifact_upload_url` are not
     registered this session (flag off), skip straight to logging — do **not**
     treat it as an error:
     1. `create_artifact_upload_url {file_name: "pr-<n>.html"}` → `{url, uploadRef}`.
     2. `curl -sS -f -X PUT -H 'Content-Type: text/html' --data-binary @work/reviews/pr-artifacts/pr-<n>.html '<url>'`
        (the explicit content-type keeps the stored MIME correct; the viewer
        renders on `type:"html"` regardless).
     3. `create_artifact {title: "PR #<n> review artifact", upload_ref: "<uploadRef>", type: "html", visibility: "public"}`
        → capture `shareUrl` as `DAM_URL` and `id` as `DAM_ID`.
     On a missing tool or any error at any sub-step: log
     `PR #<n>: DAM artifact publish skipped (<reason>)`, leave
     `DAM_URL`/`DAM_ID` empty, continue. Never fail the run over the DAM half.
   - **If no attempted target succeeded** → treat this step as `skill-errored`:
     post no comment, write no marker, keep `$BOT_LOGIN` assigned for a later
     retry, log, and stop this PR here.
3. **Comment the surviving link(s)** in a **single** PR comment — include only
   the surfaces that succeeded (bullet order: gist first, then DAM):
   ```bash
   gh pr comment <n> --repo "$REPO" --body "📊 **PR #<n> review artifact** — [gist](https://htmlpreview.github.io/?https://gist.githubusercontent.com/$BOT_LOGIN/<GIST_ID>/raw/pr-<n>.html) · [DAM Artifact Library](<DAM_URL>)"
   ```
   Drop the ` · [DAM Artifact Library](…)` segment if DAM was skipped/failed;
   drop the `[gist](…)` segment if the gist was skipped/failed. One comment,
   never two.
4. **Record the ids** in `reviews/pr-<n>.md` right after the title heading,
   each on its own line, overwriting any existing markers in place (pruning
   reads both to clean up):
   - `<!-- artifact-gist: <GIST_ID> -->` — omit the line if the gist wasn't published.
   - `<!-- artifact-dam: <DAM_ID> -->` — omit the line if DAM wasn't published.
5. **Unassign** — prefer REST (`gh pr edit` goes through GraphQL, which 401s
   in this pod):
   `gh api -X DELETE "repos/$REPO/issues/<n>/assignees" -f "assignees[]=$BOT_LOGIN" >/dev/null || gh pr edit <n> --repo "$REPO" --remove-assignee "$BOT_LOGIN"`.
   A failed unassign is logged, not fatal (next run preflight emits a
   `retry_unassign` entry — either marker prevents regeneration churn).
6. **Audit line (mandatory)**: `PR #<n>: <artifact_skill> ran → gist <GIST_ID> + DAM <DAM_ID>`
   — name only the surfaces that succeeded (e.g.
   `→ gist <GIST_ID> (DAM skipped: flag off)` when only the gist landed), or
   `PR #<n>: <artifact_skill> skipped (<install-failed|skill-errored>)`.

The saved HTML is persisted `work/` state; it (and the gist + DAM artifact) is
deleted by the prune step when the PR closes ([review.md](review.md) →
**Pruning**).
