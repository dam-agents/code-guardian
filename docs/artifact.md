# Visual PR artifact

Read this file when the preflight worklist has a non-empty `artifacts_due`.
Each entry is `{number, action}`:

- **`action: "retry_unassign"`** — the artifact already exists (the PR's
  history file carries an `<!-- artifact-gist: ... -->` marker) but the bot
  is still assigned (a previous unassign failed). Just retry the unassign
  (command in step 5 below), log the outcome, generate nothing (idempotency
  guard — no gist churn).
- **`action: "generate"`** — run the full procedure below.

Artifacts are generated by the configured `$ARTIFACT_SKILL` (installed by
preflight from its `@<owner/repo>` source). `artifact_skill: none`/missing →
the whole feature is off; preflight evaluated the **assignee gate**
(`$BOT_LOGIN` assigned to the PR) across every open non-draft PR.

> ⚠️ **Publishes to a public surface.** A "secret" gist is unlisted, not
> private — anyone with the URL can read it. That's intended, gated behind
> the explicit human assignment of `$BOT_LOGIN`.

## Procedure (per `generate` entry)

1. **Generate** — invoke `$ARTIFACT_SKILL` with the PR number (plus `$PR_DIR`
   if the PR was reviewed this run and the skill's `SKILL.md` accepts it;
   otherwise the skill works via `gh` from the number). Save the single
   self-contained HTML to `work/reviews/pr-artifacts/pr-<n>.html`
   (`mkdir -p` first). Skill error → log `skipped (skill-errored)`, stop this
   PR (no gist/comment/unassign).
2. **Publish**:
   `GIST_URL=$(gh gist create work/reviews/pr-artifacts/pr-<n>.html --desc "PR #<n> review artifact")`;
   `GIST_ID=$(basename "$GIST_URL")`. Never pass `--public`.
3. **Comment the rendered link**:
   `gh pr comment <n> --repo "$REPO" --body "📊 [PR #<n> review artifact](https://htmlpreview.github.io/?https://gist.githubusercontent.com/$BOT_LOGIN/<GIST_ID>/raw/pr-<n>.html)"`.
4. **Record the gist id** in `reviews/pr-<n>.md` as
   `<!-- artifact-gist: <GIST_ID> -->` on its own line right after the title
   heading — overwrite any existing marker in place.
5. **Unassign** — prefer REST (`gh pr edit` goes through GraphQL, which 401s
   in this pod):
   `gh api -X DELETE "repos/$REPO/issues/<n>/assignees" -f "assignees[]=$BOT_LOGIN" >/dev/null || gh pr edit <n> --repo "$REPO" --remove-assignee "$BOT_LOGIN"`.
   A failed unassign is logged, not fatal (next run preflight emits a
   `retry_unassign` entry — the gist marker prevents regeneration churn).
6. **Audit line (mandatory)**: `PR #<n>: <artifact_skill> ran → gist <GIST_ID>`,
   or `PR #<n>: <artifact_skill> skipped (<install-failed|skill-errored>)`.

The saved HTML is persisted `work/` state; it (and the gist) is deleted by
the prune step when the PR closes ([review.md](review.md) → **Pruning**).
